# Included examples

- `motion-study-540x960-silent.mp4`: original simplified 12-second, 360-frame, 30 fps smoke render of the runnable starter. This is a silent motion study with a silent audio track, not a finished narrated film or a replica of either reference. The editable composition defaults to 1080×1920; this included test was rendered at half scale.
- `motion-study-still.png`: an example starter frame.
- `luggage-sorter-plan/`: independently produced original 24-second story plan demonstrating transfer of the style to another setting. It includes checked shot coverage, original narration, scene/motion/voice direction and sources. No luggage-sorter film or voice has been rendered.

The reference reports, not the simplified demo alone, define the intended final visual quality. Add topic-specific geometry, richer surface details, projected labels and actual narration for a finished film.
