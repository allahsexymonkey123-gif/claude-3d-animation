# The Number Chooses the Route

An original **24-second production plan** for a vertical 3D explainer about an airport baggage sorter. Delivery target: **1080 × 1920, native 30 fps, 720 frames**.

Read these in order:

1. [SCRIPT.md](SCRIPT.md) — complete narration, story intent and claim boundaries.
2. [SHOT_PLAN.md](SHOT_PLAN.md) — frame ranges, camera moves, mechanism states, captions and sound cues.
3. [PRODUCTION_DIRECTIONS.md](PRODUCTION_DIRECTIONS.md) — scene registry, rendering look, animation, narrator and audio direction.
4. [story.json](story.json) — the same shot plan in the repository's machine-readable planning format.
5. [SOURCES.md](SOURCES.md) — primary technical sources and inspected style evidence.
6. [VALIDATION.md](VALIDATION.md) — completed planning checks and production work still to do.

This plan selects a **conventional belt network with a controlled side pusher/diverter**. It follows one blue suitcase from identification to its flight's make-up/collection belt. A tan suitcase demonstrates the other routing outcome. Security screening, reconciliation, transport to the aircraft and aircraft loading remain outside the depicted sequence.

The picture timeline is a production target. Narration, captions and keyword events must be fitted to an actual recorded take before animation is locked. No audio, models, rendered frames or movie have been produced; no paid service has been called.
